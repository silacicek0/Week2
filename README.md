# Week2 - Bus Route Passenger Tracking System

A Java console program that tracks passenger movement along a city bus route.

## Features
- Takes stop names, boarding and alighting counts from the user
- Calculates the number of passengers on the bus after each stop
- Warns when the bus is over capacity or when the data is invalid
- Prints all stops in a table
- Shows the busiest stop, average occupancy and the number of over-capacity stops
- Warns if passengers are still on the bus after the final stop
